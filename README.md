# Mansaleaf Production Portfolio

🌿 A modern portfolio website built for a content creator to showcase brand identity, services, and content in a clean, responsive experience.

🔗 Live site: https://mansaleafproduction.netlify.app

## ✨ Overview

This project focuses on:

- A visually engaging personal/brand portfolio
- Responsive layouts across desktop, tablet, and mobile
- Tailwind CSS-driven styling workflow
- Lightweight JavaScript interactions and animation support

## 🧰 Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript (Vanilla)
- PostCSS + Autoprefixer
- Swiper (for carousel/slider interactions)

## 📁 Project Structure

Key folders and files:

- `index.html`, `about.html`, `contact.html`, `terms.html`, `extra.html`
- `src/css/main.css` (Tailwind input)
- `dist/main.css` (compiled output)
- `tailwind.config.js`
- `postcss.config.js`

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Build Tailwind CSS (production)

```bash
npm run build
```

### 3. Watch Tailwind CSS changes (development)

```bash
npm run watch
```

### 4. Run local server

```bash
npm run start
```

## 📜 Available Scripts

- `npm run build`: Compiles and minifies CSS to `dist/main.css`
- `npm run watch`: Rebuilds CSS on file changes
- `npm run start`: Serves the project locally with Live Server

## 🛠 Development Notes

- Tailwind content scanning includes files in root, `src`, and `dist`.
- Styling customizations (animations/colors/font sizing) are defined in `tailwind.config.js`.

## 🤝 Collaboration Process

The project was developed with a client-first workflow:

- Requirement gathering and audience targeting
- Wireframing and layout planning
- Front-end implementation and iteration
- QA, optimization, and deployment

## 📚 Lessons Learned

- Clear communication early reduces rework later.
- Structured planning helps ship faster and cleaner.
- Responsive testing from day one improves final quality.
